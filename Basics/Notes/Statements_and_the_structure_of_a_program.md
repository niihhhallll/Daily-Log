# Statements 
#### **A statement is a type of instruction that causes the program to perform some action** 

#### **Most of the statements ends in a semicolon; if you see a line that ends in a semicolon, it's probably a statement**

## Different Type's Of Statements 
- #### Declaration Statments 
- #### Jump Statements
- #### Expression Statements 
- #### Compound Statements 
- #### Selection Statements[conditionals]
- #### ETC.... 

### Functions and main function 
- #### Statements are typically grouped into units called functions 
- #### A function is a collection of statements that get executed sequentially[From top to bottom] 

- #### ***Every C++ Program must  have a special function named main***
